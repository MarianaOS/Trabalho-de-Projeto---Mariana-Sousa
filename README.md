Neste repositório encontra-se o notebook com a arquitetura final da CNN desenvolvida e do processo de Transfer Learning.

Os links para os conjuntos de dados serão aqui disponibilizados.

Dataset 1 - Oxidized and non-oxidized tire sidewall and tread images (Siegel, 2021) - https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/Z3ZYLI
Dataset 2 - Digital images of defective and good condition tyres (Pathmanaban et al., 2023) - https://data.mendeley.com/datasets/bn7ch8tvyp/1
Dataset 3 - TyreNet: A High-quality Annotated Dataset for Tyre Defect Classification with Deep Learning Models (Mahendrada et al., 2024) - https://data.mendeley.com/datasets/32b5vfj6tc/1
